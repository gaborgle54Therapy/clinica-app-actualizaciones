# Clínica App · instaladores

Este repositorio **solo** guarda los instaladores de Clínica App para Windows y sus actualizaciones automáticas. **No contiene código fuente.**

- Descarga la versión más reciente en [Releases](../../releases/latest).
- La app instalada revisa sola si hay versiones nuevas y se actualiza.
- Para usar la app se necesita una clave de licencia. Sin ella solo está disponible el modo demo con datos ficticios.
